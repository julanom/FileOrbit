FileOrbit for Linux (x64 and ARM64 preview)

Run ./Filee to open FileOrbit, or ./filee-cli help for the compatibility CLI.
The binary retains its internal engine name; the desktop launcher is FileOrbit.

Run ./install.sh to install for the current user. Python 3 is required.
It creates a FileOrbit launcher and ~/.local/bin/fileorbit, without root.
Run ./uninstall.sh to remove this installation. Settings and converted files remain.
An existing installation is never overwritten.

Use Ubuntu 24.04 or newer. This preview does not promise Ubuntu 22.04 compatibility.
The .NET runtime, rhwp, and 7-Zip are bundled; system libraries are still required.

Ubuntu 24.04 dependencies:
sudo apt-get install ca-certificates libc6 libgcc-s1 libgssapi-krb5-2 libicu74 libssl3t64 libstdc++6 tzdata zlib1g libfontconfig1 libfreetype6 libx11-6 libice6 libsm6 libxrandr2 libxkbcommon0 libxi6 libxtst6 libxt6 fonts-noto-cjk python3

Use an X11 desktop for global gestures. Wayland is experimental and requires
compositor-specific setup and elevated input access; the default supported
fallback is dropping files into the workspace. No permission to raw keyboard
input is granted by this installer.

Other converters are downloaded from their official sources through the Converters
page or discovered on the system. Format support depends on available engines.
Packages are built on Ubuntu 24.04; GUI behavior across distributions is not
fully verified. Report problems at https://github.com/julanom/FileOrbit/issues.
